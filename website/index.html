04 / AYUDA

Empieza por aquí.

Una guía inicial para descargar Phaedra y seguir su evolución. El manual de usuario completo aún está en preparación.

¿Cómo descargo Phaedra?

Accede a Descargas y pulsa «Obtener ZIP gratuito». Se abrirá el archivo alojado en la publicación oficial de GitHub. Comprueba los archivos antes de ejecutarlos y recuerda que es una versión experimental.

¿Hay que pagar o crear una cuenta?

No. El acceso al paquete publicado es gratuito y no exige una cuenta propia en Phaedra. No se ha anunciado ningún plan de pago.

¿Puedo usarlo para trabajos profesionales?

La meta es ofrecer una estación de trabajo seria, pero la estabilidad todavía requiere comprobaciones. Para proyectos importantes, conserva copias de seguridad y prueba las funciones en sesiones que puedas recuperar.

¿Cómo informo de un error?

Utiliza el apartado Issues en GitHub. Incluye tu versión de Windows, la versión de Phaedra, los pasos para reproducir el error y, cuando sea posible, una captura.

¿Phaedra funciona en otros sistemas?

Esta web se centra en la distribución para Windows. Aquí no anunciamos compilaciones oficiales verificadas para macOS o Linux.

¿Qué licencia tiene Phaedra?

El repositorio incorpora código derivado de Ardour y avisos de licencia GNU GPL. La gratuidad del programa no elimina esas obligaciones. Puedes revisar el archivo COPYING y el código fuente.
