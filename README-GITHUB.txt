Phaedra GitHub source archives
==============================

To compile Phaedra from source, use a full Git checkout. Automatically
generated GitHub archives may omit versioning information that Waf requires.
Do not treat a GitHub-generated source archive as a verified Windows release.

The official workflow must build the executable, package required runtime
files, run smoke tests and publish integrity hashes before distribution.
See .github/workflows/build-release.yml and README.

Licenses and upstream source attributions are retained in COPYING and
corresponding source files.
